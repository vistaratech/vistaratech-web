## 🚀 Overview

This repository contains the official, high-performance web platform for **Vistara Tech**. Built with modern technologies including React, TypeScript, Three.js (React Three Fiber), and Tailwind CSS to deliver an interactive 3D user experience and smooth micro-animations.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **3D & Visuals**: Three.js, React Three Fiber, React Drei
- **Animations**: Framer Motion, Lenis Smooth Scroll
- **Styling**: Tailwind CSS
- **Bundler**: Vite

## 💻 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd vistara-tech
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
